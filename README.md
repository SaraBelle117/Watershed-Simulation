## Description
This program will simulate water flow over a terrain when it rains. The purposes of this assignment are to practice writing a program in C language, and also help indicate where water is most likely to pool in a given area. The data comes from LIDAR for the land height at 1 meter resolution.

Features: stat function (in pointcloud.c) which prints the minimum, maximum, and average height for the given data points. It also prints the x & y coordinates for the min and max data points.
