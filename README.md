## Description
This program will simulate water flow over a terrain when it rains. The purposes of this assignment are to practice writing a program in C language, and also help indicate where water is most likely to pool in a given area. The data comes from LIDAR for the land height at 1 meter resolution.

## Features: 
Stat1() function (in pointcloud.c) which prints the minimum, maximum, and average height for the given data points. It also prints the x & y coordinates for the min and max data points. The stat1(...) function does the same thing, but instead of holding the x & y values of the min and max z points, it also will hold the min and max x & y values. The functions readPointCloudData(...) and imagePointCloud(...) can be used to read the points from the .xyz file and output to out.gif.
